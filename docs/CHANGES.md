# 원문 보존 및 개선 내역

## 스크롤 없는 수업 화면 · 2026-11-03

- 실제 브라우저 수업 영역(615×532)에서도 본문 전체가 화면 안에 들어오도록 슬라이드 실제 높이를 측정해 자동 맞춤합니다. 자료 공개·창 크기 변경 때도 다시 계산합니다. 본문을 잘라서 숨기는 방식이 아닙니다.
- 시간표 작성과 좌우 비교는 4행씩 표시하고 ‘이전 행 / 다음 행’으로 넘깁니다. 행 추가 시 새 행이 있는 페이지를 열며, 번호·입력·자동 저장은 유지됩니다.
- 페이지 스크롤과 시간표 내부 스크롤을 제거했습니다. 긴 자유 답변의 입력칸 내부 스크롤, 목차와 교사 패널은 필요에 따라 유지합니다.

## 후속 수정 · 2026-11-03

- 요청에 따라 상단 단계명과 페이지 위의 단계 표시를 ‘우리나라 학교생활은 어떤 모습일까?’, ‘중국의 학교생활은 어떤 모습일까?’, ‘두 나라의 학교생활은 무엇이 같고, 왜 다를까?’, ‘다름을 존중하며 어떻게 소통해야 할까?’로 교체했습니다. 긴 문장이 줄바꿈되도록 배치를 조정했습니다.
- GitHub Pages용 상대 경로 빌드 설정과 자동 배포 워크플로를 추가했습니다. 기존 학생 입력 데이터나 활동 내용은 변경하지 않았습니다.

## 보존한 내용

- 전체 15페이지와 네 질문의 수업 순서, 학습목표, 학생 발문, 교과서 설명, 교사 멘트를 그대로 데이터에 보존했습니다.
- ‘일반적으로’, ‘많은 학생들’, ‘많은 학교들’이라는 범위 표현을 유지했습니다. 한국 학교생활을 시간·제도·관행으로 미리 일반화하지 않았습니다.
- 원본 12회 이미지 사용에 해당하는 고유 파일 10개를 추출했습니다. 표지·학급 생활·낮잠·시험·휴식 자료와 눈 체조 6단계를 모두 사용합니다. 삽화는 추가 생성하지 않았습니다.
- 원문 사본을 `original.html`로 보관했습니다. 이미지 비율을 유지하고 사진의 잘림을 유발했던 cover 방식은 contain 방식으로 바꿨습니다.
- 교과서 설명에 해당하는 새 문화적 사실은 추가하지 않았습니다. 高考 시기·시험 일수·채점 표시 등도 원문 그대로입니다.

## 구조와 기능 변경

- 고정 1600×900 슬라이드 축소 방식에서 반응형 웹앱으로 전환했습니다. 제목, 수업 단계, 목차, 진행 표시, 고정 이동 버튼을 제공합니다.
- 15개 슬라이드 함수와 공통 상호작용 컴포넌트로 분리하고 원문 내용은 JSON 데이터로 관리합니다. 원본 인라인 스타일·script는 실행하지 않습니다.
- 자문화 활동에 개인 경험 복수 선택과 다른 경험 작성 기능을 추가했습니다. 교사의 인원 집계 그래프는 별도로 유지했습니다.
- 원본의 작성 완료·선택 공개·O/X·타이머·이미지 확대 기능을 React로 다시 구현했습니다.
- 월 선택 버튼의 표시 단위는 원문의 ‘월’을 중국어 ‘月’로 바꿨습니다. 1~12 선택 범위와 ‘중국은 9월에 새 학년이 시작됩니다.’라는 교과서 설명은 유지합니다.
- 눈 체조 6개의 작은 동시 표시를 ‘단계별 탭 + 그림 + 해당 원문 설명’으로 바꿨습니다. 모든 단계 설명은 수정하지 않았습니다.
- 중국·우리 학교 시간표 편집과 행 추가·삭제를 유지하고, 13페이지에 실제 작성 결과의 좌우 비교 보기를 추가했습니다. 입력 예시를 중국의 정해진 일과로 제시하지 않습니다.
- 교사 멘트는 기본 숨김, 페이지 이동 시 닫힘을 유지합니다. N 키와 버튼을 모두 지원합니다. 버튼·링크 초점에서는 Enter·Space의 기본 동작을 지킵니다.
- 자동 저장·JSON 파일 저장/불러오기·전체 화면·입력 수정 시 완료 해제·오류 안내·키보드 초점 표시·확대 창 Escape/초점 복귀를 추가했습니다.

## 추가 문구 목록

교육적 보조 문구:

1. ‘교과서 50~51쪽에 소개된 학교생활입니다. 학교와 지역에 따라 다를 수 있습니다.’ — 타문화 발견 단계의 하단 안내. 원문 설명과 구별됩니다.
2. ‘문장을 눌러 내 경험을 선택하세요. 인원은 교사가 직접 집계합니다.’ — 자문화 선택과 수동 집계를 구분합니다.
3. ‘다른 경험이 있다면 한 줄로 적어 보세요.’ — 학생 경험을 추가로 작성합니다.
4. ‘교류 상황 · 중국 학생과 서로의 학교생활을 소개하다가 생각의 차이를 만났습니다.’ — 14페이지 기존 발문을 구체적인 상황에 연결한 설명용 문구입니다. 중국 학교의 사실 설명이 아닙니다.
5. ‘내 경험 말하기 → 상대의 경험 묻기 → 차이의 배경 듣기’ — 존중하는 소통을 생각하는 과정 안내이며 모범 답안이나 채점 기준이 아닙니다.

- ‘이 기기에 자동 저장됨’, ‘자동 저장 불가 · 파일 저장 필요’, ‘결과 저장 ↓’, ‘불러오기 ↑’, ‘전체 화면 ⛶’, ‘목차 ≡’, ‘확대 보기 ↗’, ‘원본 비율’, ‘닫기 ×’.
- ‘시간표 작성’, ‘두 시간표 나란히 보기’, ‘내가 경험한 우리 학교’, ‘조사한 중국 학교’, ‘자료:’, ‘학교명 또는 링크 미입력’, ‘시각 미확인’, ‘활동 미입력’, ‘시간표에 작성한 내용이 여기에 표시됩니다.’, ‘행을 추가해 일과를 작성하세요.’.
- ‘우리 반 인원’, ‘다른 경험 한 줄’, 단계 표시 ‘STEP 01 / 06’ 등, ‘이전 단계’, ‘다음 단계’, ‘토의 시간이 끝났습니다.’, ‘TEACHER NOTES’.

- 비교 활동 11·12페이지에 ‘작성 완료’와 토의 타이머를 추가했습니다. 기존의 네 비교 입력 항목은 유지했습니다.

## 임의로 적용하지 않은 내용 개선 제안

1. 원본은 교과서 50~51쪽을 근거로 제시하지만 교과서명·출판사·판본·발행연도는 확인할 수 없습니다. 교사가 원자료 서지와 그림의 이용 범위를 확인하고 정확한 출처를 추가하는 것이 좋겠습니다.
2. 새 학년·학급 운영·기숙사·교복·高考 일정·채점 표시의 서술은 원본 그대로입니다. 최신 정보나 특정 지역 사례로 확대하기 전에 해당 교과서와 원자료를 확인해야 합니다. 이 작업에서는 사실 문장을 임의 수정하거나 웹에서 다른 사실을 덧붙이지 않았습니다.
3. 기존 시각자료 중 표지·학교생활 이미지는 삽화로 보입니다. 실제 학교 촬영 사진처럼 해석되지 않도록 수업 중 자료 성격을 안내하는 것을 제안합니다. 새 사실을 증명하는 사진으로 대체하지 않았습니다.
4. 원본 9페이지 제목에는 ‘낮잠 시간’이 있지만 활동 내용은 눈 체조입니다. 제목은 보존했습니다. ‘눈 보호 체조 체험하기’로 바꾸려면 교사 검토 후 수정할 수 있습니다.
5. 240×240의 눈 체조 그림은 고해상도 원본을 확보하면 교실 시인성이 더 좋아집니다. 현재는 비율·원본 픽셀 크기를 지키고 단계별로 분리했습니다.

문화의 우열 판단, 전국 단위 일반화, 임의의 중국 학교 하루 시간표, 정답을 강요하는 성찰 예시는 추가하지 않았습니다.
