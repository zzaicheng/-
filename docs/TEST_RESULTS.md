## 발견 후 수정한 사항

- 작은 화면에서 투표·눈 체조·시간표·비교 입력·완료 버튼의 세로 넘침을 발견했습니다. 별도 compact 스타일로 문장·그림을 보존하면서 배치를 조정하고 다시 전체 검사했습니다.
- 큰 화면의 6·10·11·12·13페이지에도 세로 넘침이 있어 시간표 내부 높이와 입력 영역·간격을 조정한 뒤 다시 검사했습니다.
- 원본 바이두 주소의 줄바꿈을 제거해 검색 URL이 끊기지 않게 했습니다.
- favicon 404를 해결한 후 콘솔 오류 0건을 확인했습니다.
- 시간표 활동칸은 datalist가 있어 접근성 역할이 combobox입니다. 테스트를 정확한 필드 이름으로 수정하여 행 편집을 검증했습니다.

## 검증 범위와 한계

- 기준 해상도, 브라우저 배율 100%, 기본 데이터 및 테스트 답변을 기준으로 확인했습니다. 200행까지의 긴 시간표는 표 내부 스크롤, 작은 창과 긴 입력에는 콘텐츠/입력칸 스크롤을 허용합니다. 모든 임의의 문장 길이나 모든 화면 확대 배율을 한 화면에 넣는다는 의미는 아닙니다.
- 바이두는 링크의 검색어·형식을 확인했습니다. 중국 측 검색 서비스의 가용성과 검색 결과의 사실성은 검증하지 않았습니다.
- 교과서 원본·판본이 별도 제공되지 않아 첨부 HTML의 원문 보존을 검사했습니다. 사실 설명을 최신 정보로 재작성하지 않았습니다.
- 전자칠판·프로젝터의 실제 거리와 색감, Safari·Firefox 및 모바일 실기기, 여러 학생의 실시간 합산은 검사 범위가 아닙니다. 학생 간 실시간 합산 기능은 없습니다.
- 타이머는 페이지를 떠나면 초기화됩니다. 저장 파일은 학습 답변·선택·집계·완료 상태·시간표를 보존합니다.
