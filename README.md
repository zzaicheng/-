# 문화 사이 · 중국의 학교생활

## GitHub Pages 배포 (2026-11-03 수정)

상단 수업 단계는 네 가지 질문 전문으로 표시합니다. `vite.config.js`의 `base: './'`로 GitHub Pages 하위 경로에 대응하며 `.github/workflows/pages.yml`로 main 브랜치 변경 시 빌드·배포합니다. 저장소 Settings → Pages → Source를 **GitHub Actions**로 지정하세요. 현재 배포 대상은 `zzaicheng/-`이고 배포 완료 후 주소는 `https://zzaicheng.github.io/-/`입니다. 저장소 URL만 바꿔서는 배포되지 않으며 GitHub Pages 활성화와 워크플로 성공을 확인해야 합니다.

GitHub Pages는 기존 Sites와 다른 접속 주소이므로, 기존 브라우저 자동 저장 답변을 옮기려면 기존 사이트에서 결과 파일을 저장한 뒤 새 사이트에서 불러오세요. 학생 답변은 GitHub에 업로드하지 않습니다.

참고: [Vite 공식 배포 안내](https://vite.dev/guide/static-deploy#github-pages), [GitHub Pages 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

고등학교 2학년 중국어 상호문화교육 수업용 React + Vite 웹앱입니다. 원본 15페이지의 순서, 학습목표, 학생 발문, 교과서 설명, 교사 멘트를 보존했습니다. 원본 HTML은 실행 지시가 아닌 수업 내용으로만 취급했습니다.

## 바로 수업하기

1. ZIP을 압축 해제합니다. `dist`와 `public` 폴더를 함께 유지하세요.
2. Windows에서 `수업실행.cmd`를 더블클릭합니다. 이 PC의 Codex에 포함된 Node.js도 자동으로 찾습니다. 다른 PC에서는 Node.js 22 이상이 필요합니다.
3. 브라우저에서 **http://127.0.0.1:4173** 을 엽니다. 명령 창은 수업이 끝날 때까지 열어 둡니다.
4. 종료하려면 명령 창에서 Ctrl+C를 누릅니다.

빌드된 앱과 모든 이미지는 로컬에 포함되어 있습니다. 실행에는 패키지 설치나 인터넷이 필요 없습니다. 바이두 검색 링크는 인터넷이 필요합니다. `dist/index.html`을 직접 더블클릭하는 방식은 지원하지 않습니다.

## 개발 실행

```sh
npm install
npm run dev
```

출력된 주소(기본 http://127.0.0.1:5173)를 엽니다. pnpm을 쓰면 `pnpm install`, `pnpm dev`도 가능합니다. `pnpm-lock.yaml`을 포함했습니다. pnpm에서 esbuild의 설치 스크립트가 차단되었다는 알림이 표시되더라도 빌드가 성공하면 별도 승인 작업은 필요하지 않습니다.

```sh
npm test
npm run test:browser
npm run build
npm run preview
```

브라우저 테스트는 개발 서버가 5173 포트에서 실행 중이어야 하며, 기본적으로 설치된 Microsoft Edge를 headless 모드로 사용합니다. Chrome은 `BROWSER_CHANNEL=chrome` 환경 변수로 선택합니다. 테스트용 브라우저 저장소는 새로 생성하므로 실제 학생 답변을 건드리지 않습니다. 스크린샷 30장과 검사 JSON은 `test-results/`에 생성됩니다.

## 교실 사용법

- 아래 이전·다음 버튼 또는 ← → 키로 이동합니다. 목차에서 15페이지 중 원하는 페이지로 이동할 수 있습니다.
- N 키 또는 하단 ‘교사 멘트’ 버튼으로 교사 멘트를 켭니다. 기본은 숨김이며 페이지를 이동하면 닫힙니다. 전자칠판에 표시하면 학생도 볼 수 있으니 교사만 확인할 때 활용하세요.
- 입력칸·선택칸·버튼·링크에 초점이 있으면 전역 이동 단축키가 동작하지 않습니다. 입력 중 Enter와 Space는 페이지를 이동시키지 않습니다. 전역 이동은 방향키만 사용합니다.
- 사진·그림을 클릭하면 원본 비율로 확대합니다. Escape 또는 ‘닫기’로 나옵니다.
- 자신의 경험 문장을 여러 개 선택할 수 있습니다. 집계 그래프의 인원은 교사가 직접 입력합니다. 비율은 해당 페이지에 입력된 전체 선택 건수 기준이며 학생 수나 전국 통계가 아닙니다. 복수 선택이므로 비율을 학생 비율로 해석하지 마세요.
- O/X와 월 선택 후에는 교과서 설명을 확인합니다. 6페이지는 O/X와 서술형 모두 작성한 다음 ‘작성 완료’를 눌러야 자료가 공개됩니다.
- 눈 보호 체조는 1~6단계 버튼으로 그림과 원문 설명을 각각 봅니다. 소감을 입력하고 완료합니다.
- 중국 일과표에는 조사한 학교명이나 링크를 입력합니다. 시간과 활동을 임의의 정답으로 미리 채우지 않았습니다. 행을 삭제하면 순서가 자동으로 다시 매겨집니다. 시간표는 4행씩 표시하며 이전 행·다음 행 버튼으로 넘깁니다.
- 13페이지 ‘두 시간표 나란히 보기’에서 실제 입력한 우리 학교 경험과 조사한 중국 학교를 비교합니다.
- 타이머는 시작·일시정지·초기화가 가능합니다. 페이지를 떠나면 정지되고 재진입 시 해당 페이지의 기본 시간으로 돌아갑니다. 타이머는 학습 답변 파일에 포함하지 않습니다.
- 전체 화면 버튼은 브라우저 기능을 사용합니다. 환경에 따라 F11도 가능합니다.

## 저장과 불러오기

입력한 답변·완료 여부·선택·집계·시간표는 같은 브라우저의 localStorage에 자동 저장됩니다. 페이지 이동과 새로고침 후 유지됩니다. ‘결과 저장’은 JSON 파일을 내려받고, ‘불러오기’는 그 파일의 학습 결과로 현재 결과를 교체합니다. 교체 전에 현재 결과를 파일로 저장하세요. 완료한 답변을 수정하면 완료 상태가 해제됩니다. 잘못된 JSON은 오류 메시지를 표시하고 기존 결과를 유지합니다.

학생 계정이나 서버 수집 기능은 없습니다. 개인 노트북마다 독립된 결과이며 교사 화면과 실시간 합산되지 않습니다. 브라우저 데이터 삭제·시크릿 모드·다른 접속 주소에서는 결과가 유지되지 않을 수 있습니다. 다음 학급에서는 새 브라우저 프로필을 사용하거나 빈 상태의 JSON을 불러오세요. 자동 저장 실패 시 상단에 파일 저장 안내를 표시합니다.

## 내용과 디자인 수정

```text
src/data/slides.json    원문 내용·노드·교사 멘트 (실행 코드를 포함하지 않는 데이터)
src/slides.jsx         15개 독립 슬라이드 컴포넌트와 단계별 눈 체조·시간표 비교
src/components.jsx     공통 입력·사진·투표·타이머·시간표 및 원문 노드 렌더러
src/state.mjs          저장 파일 검증·초기 상태·비율 계산
src/main.jsx           앱·페이지 이동·단축키·저장/불러오기·교사 패널
src/style.css          기본 시각 디자인·큰 화면·모바일 대응
src/compact.css        1366×768 교실 화면용 배치 조정
src/FitSlide.jsx       남은 화면 영역에 슬라이드 자동 맞춤
src/fit.css            스크롤 없는 화면과 작은 창 배치
src/PagedSchedules.jsx 4행 단위 시간표 편집·좌우 비교
public/assets/         원본에서 추출한 이미지 10개
docs/original.html     제공된 원본 파일 사본
docs/SOURCE_ANALYSIS.md 원본 전체 15페이지 분석
docs/CHANGES.md        보존 내용·추가 문구·별도 개선 제안
docs/TEST_RESULTS.md   실제 검사 결과와 한계
tests/                 단위 및 브라우저 통합 테스트
dist/                  실행 가능한 빌드 산출물
```

일반 슬라이드의 문장은 `slides.json`에서 수정합니다. 눈 체조는 원문 데이터에서 단계별 그림과 문장을 읽습니다. 새 상호작용은 `components.jsx`의 공통 컴포넌트를 재사용하거나 별도 슬라이드 컴포넌트로 만드세요. `SourceNode`는 알려진 태그를 React로 렌더링하며 원본 script, 이벤트 핸들러, style을 실행하지 않습니다. 모든 화면을 검증한 후 `npm run build`로 `dist`를 갱신합니다.

1366×768 및 1920×1080을 기준으로 검증합니다. 브라우저 확대는 100%를 권장합니다. 작은 창에서는 남은 수업 영역에 맞춰 슬라이드 전체를 자동 축소하여 페이지 스크롤을 없앴습니다. 전체 화면 버튼을 사용하면 더 크게 볼 수 있습니다. 긴 답변은 입력칸 내부에서 스크롤할 수 있습니다. 그림은 비율과 원본 픽셀 크기를 유지하며 확대 창에서도 낮은 해상도를 강제로 늘리지 않습니다.

기존 원고의 사실 진술은 새로 검증하거나 최신 사실로 수정하지 않았습니다. 수업 전 교과서 판본과 연결해 확인할 항목은 `docs/CHANGES.md`에 별도 정리했습니다.
